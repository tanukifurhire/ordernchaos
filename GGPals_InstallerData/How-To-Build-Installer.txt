ORDER N CHAOS INSTALLER
=======================

HOW TO BUILD THE INSTALLER
---------------------------

STEP 1: Install Inno Setup
- Download from https://jrsoftware.org/isinfo.php
- Run the installer with default options

STEP 2: Build Release Version
- Open Visual Studio
- Set configuration to ReleaseGame
- Build > Build Solution
- Output: GGPals_CustomEngine\GGEngine\bin\ReleaseGame\OrderNChaos.exe

STEP 3: Run the automated build script
From the repo root, double-click:
  GGPals_InstallerData\BuildInstaller.bat

The script handles everything automatically. The VC++ Redistributable is
already committed to git at GGPals_InstallerData\REDIST\VC_redist.x64.exe
and will be bundled into the installer automatically.

------------------------------------------------------------------------------
MANUAL STEPS (only if the script fails)
------------------------------------------------------------------------------

STEP 4: Create GAMEDIRECTORY Structure
Create this exact folder structure in GGPals_InstallerData\GAMEDIRECTORY\

GGPals_InstallerData\GAMEDIRECTORY\
    GGPals_CustomEngine\
        GGEngine\
            bin\
                Release\
                    OrderNChaos.exe
                    fmod.dll
                    fmodL.dll
                    lua51.dll
            config\
                config.json
        GGProjects\
            Order&Chaos\
                Assets\
                    (copy entire GGPals_CustomEngine\GGProjects\Order&Chaos\Assets\ here)
        EngineAssets\
            Fonts\
                (copy entire GGPals_CustomEngine\EngineAssets\Fonts\ here)
            Shaders\
                (copy entire GGPals_CustomEngine\EngineAssets\Shaders\ here)
            Textures\
                (copy entire GGPals_CustomEngine\EngineAssets\Textures\ here)

NOTE: The folder layout inside GAMEDIRECTORY must exactly mirror the source
project layout. The game resolves all paths relative to the exe location using
GetModuleFileNameW(), so the relative offsets must be preserved.

STEP 5: Build Installer
- Navigate to GGPals_InstallerData\ folder
- Right-click InstallScript.iss
- Select "Open with Inno Setup Compiler"
- Click Build > Compile (or press Ctrl+F9)
- Wait for "Compile completed successfully"
- Output file: GGPals_InstallerData\INSTALLER\OrderNChaos_Setup.exe

------------------------------------------------------------------------------
VC++ REDISTRIBUTABLE NOTES
------------------------------------------------------------------------------
The installer bundles VC_redist.x64.exe so players do not need to install it
manually. During installation it will:
- Skip silently if the runtime is already installed (no error dialog)
- Install silently via UAC prompt if not present

If a player gets a launch error about missing DLLs (VCRUNTIME140.dll, etc.)
despite the installer running, they can install the runtime manually from:
  https://aka.ms/vs/17/release/vc_redist.x64.exe

------------------------------------------------------------------------------
UPDATING ASSETS
------------------------------------------------------------------------------
To update assets for the installer:
1. Make changes to GGPals_CustomEngine\GGProjects\Order&Chaos\Assets\
2. Re-run BuildInstaller.bat -- it wipes GAMEDIRECTORY and rebuilds from scratch

To update engine assets (fonts/shaders):
1. Make changes to GGPals_CustomEngine\EngineAssets\
2. Re-run BuildInstaller.bat

------------------------------------------------------------------------------
TESTING THE INSTALLER
------------------------------------------------------------------------------
Before submitting:
1. Run OrderNChaos_Setup.exe
2. Install to default location
3. Verify game launches
4. Test Start Menu shortcut: DigiPen > Order N Chaos
5. Test Uninstall: Start Menu > DigiPen > Order N Chaos > Uninstall
6. Verify all files are removed after uninstall

------------------------------------------------------------------------------
TROUBLESHOOTING
------------------------------------------------------------------------------

Problem: Game won't launch from GAMEDIRECTORY
Solution: The folder structure inside GAMEDIRECTORY must exactly mirror the
          source project layout -- specifically GGProjects\Order&Chaos\Assets
          and EngineAssets must both be present.

Problem: Black screen or missing textures
Solution: EngineAssets (shaders + fonts) was probably not copied. Re-run the
          script and verify the EngineAssets folder is present in GAMEDIRECTORY.

Problem: Missing DLL error on launch
Solution: Copy all .dll files from GGEngine\bin\ReleaseGame\ to GAMEDIRECTORY.

Problem: Installer fails to build
Solution: Verify Inno Setup 6 is installed at the default path and
          GGPals_InstallerData\REDIST\VC_redist.x64.exe exists in the repo.

Problem: Script exits with "Assets folder not found"
Solution: Assets are at GGPals_CustomEngine\GGProjects\Order&Chaos\Assets\
          Verify this path exists before running the script.
